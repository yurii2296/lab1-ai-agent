### Призначення репозиторію

Репозиторій містить інструкції агента GitHub Copilot, три спеціалізовані skills, шість prompt-команд та документацію для майбутньої генерації невеликого JavaScript-проєкту з тестами, виконуваними файлами Node.js SEA та кросплатформним CI.

На першому етапі створюються **лише агент, його інструкції та документація**. JavaScript-застосунок, тести, `package.json`, lock-файл і workflow мають бути згенеровані агентом під час наступного етапу.

### Структура матеріалів

- `.github/agents/build-engineer.agent.md` — роль і правила агента Build Engineer.
- `.github/skills/` — процедури створення проєкту, складання/тестування та GitHub Actions.
- `.github/prompts/` — окремі інструкції-команди та оркестратор `init`.
- `docs/architecture.md` — цільова архітектура та межі відповідальності.
- `docs/usage.md` — запуск команд, зокрема коли prompt-файли не показані як slash-команди.
- `docs/ai-log.md` — журнал взаємодії з AI-агентом.

### Як скористатися агентом

Відкрийте репозиторій у VS Code із GitHub Copilot, виберіть агента **Build Engineer** і попросіть виконати `.github/prompts/init.prompt.md`. У версіях VS Code, де prompt-файли не доступні як slash-команди, явно попросіть агента прочитати цей файл та виконати інструкції з нього. Детальніший порядок наведено в [docs/usage.md](docs/usage.md).

### Обмеження першого етапу

У репозиторії навмисно поки немає застосунку, тестів, `package.json`, `package-lock.json` або `.github/workflows/ci.yml`. Їх має створити агент у наступному етапі відповідно до специфікації в його інструкціях.
